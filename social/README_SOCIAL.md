# Social Accounts — Step‑by‑Step Quick Guide

This guide walks you through creating Facebook Page, Instagram Business, and X accounts with the ready text and images provided in this `social/` folder.

Before you start
- Verify access to `peakcarpenter538@gmail.com` (you will receive confirmation emails).
- Prepare a profile image (use one of the images in `img/` or a logo). Recommended: 400×400 px.
- Open `social/IMAGE_TEMPLATES.html` in a browser to export promotional images.

Facebook Page (quick)
1. Log in to Facebook or create a personal account.
2. Click Menu → Create → Page → Business or Brand.
3. Enter Page name: `Peak Carpenters`. Select categories: Carpenter, Furniture Maker.
4. Paste the About text from `social/PROFILES.md` and add email/phone/website.
5. Upload profile image and cover (820×312 px). Use `social/IMAGE_TEMPLATES.html` if you want a cover with overlay text.
6. Settings → Messaging: enable people to message the Page.
7. Publish the Page.

Instagram Business (quick)
1. Open Instagram app or web → Sign up with email `peakcarpenter538@gmail.com`.
2. Choose username and profile name `Peak Carpenters`.
3. Upload profile image (320×320). Add bio from `social/PROFILES.md` and website URL.
4. Profile → Settings → Account → Switch to Professional Account → Business.
5. Connect to Facebook Page to enable cross-posting (optional).

X (Twitter) (quick)
1. Go to x.com/signup and register with `peakcarpenter538@gmail.com`.
2. Choose handle (e.g., `@peakcarpenters`).
3. Upload profile image and header (1500×500 px). Paste bio from `social/PROFILES.md`.
4. Make the profile public in Settings → Privacy.

Posting & scheduling
- Use `social/POST_TEMPLATES.md` for captions, hashtags, and image suggestions.
- Create images by opening `social/IMAGE_TEMPLATES.html` and replacing background URLs if desired, then export PNGs (1080×1080).
- Use Meta Business Suite (free) to schedule FB+IG posts; use TweetDeck for X scheduling.

Security
- Enable email verification and two-factor authentication (2FA) on each account and on the Gmail account.
